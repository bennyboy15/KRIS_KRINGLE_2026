# Kris Kringle Draw 2026

Live at https://bennyboy15.github.io/KRIS_KRINGLE_2026/

## Running the draw

1. The organiser opens the link above and taps **Make the draw**.
2. Send everyone the link it gives you (the part after `#draw=` is the draw code).
3. Each person opens that link, taps their own name, and reveals who they're buying for.

Everyone who opens the same link sees the same draw. Nobody gets themselves or their partner.

To redraw, use **Start a new draw** on the device that made the draw, then send out the new link. Old links keep showing the old draw.

The names live in `COUPLES` in `index.html`. Changing them, or their order, changes the result for every existing link, so make a new draw after any edit.
